# Ayush360 – Admin Module Backlog

**Status:** not started; this is the agreed list of what the Admin module must cover.
**Last updated:** 21 October 2026
**Keep this file current:** whenever a feature ships with a hard-coded rule or a value "an admin should set later",
add it here (section 3) with where it lives in the code.

The Admin module is for the hospital's own administrator (role *Admin*, e.g. `PS10210`). Platform-level work for the
Ayush360 team (onboarding a new hospital, licences) is listed separately in section 6.

## 3. Settings currently hard-coded (move to Admin → Settings)

| # | Setting | Value today | Where it lives |
|---|---|---|---|
| 3.1 | Free follow-up window (days, same doctor) | Per hospital: Swetha 10, Green Valley 0 | `settings.follow_up_free_days` (already in the DB; needs a screen) |
| 3.2 | How far ahead appointments can be booked | 30 days | `RegistrationService.RescheduleMaxDays`; FE `BOOKING_MAX_DAYS` |
| 3.3 | How far ahead a visit can be moved | 30 days | same constant as 3.2 |
| 3.4 | Phone bookings: minimum patient details | Today a new patient needs all details (incl. address) even for a phone booking; option: name, gender, age, mobile only, rest at check-in | `ValidatePatient` (server), `validatePatient` (FE) |
| 3.5 | Late arrival for a booked token | None: a booked patient keeps their token place whenever they check in. Option: "more than N min late → end of line" | FE `sortQueue` (front desk and doctor) |
| 3.6 | Cancel reasons list | Patient did not come · Patient asked to cancel · Booked by mistake · Doctor not available · Other | FE `VisitActions.CANCEL_REASONS` |
| 3.7 | Doctor pause reasons | Fixed list (operation theatre, emergency patient call, lunch break, …) | FE shared doctor-availability list (`src/shared`) |
| 3.8 | Default consultation time (for expected time) | 10 min; "today" pace after 3 patients seen; else last 30 days | `DoctorAvailabilityService.DefaultConsultMinutes` |
| 3.9 | "Doctor idle" alert at the desk | 20 min with patients waiting | FE `FrontDeskQueuePage.IDLE_MINUTES` |
| 3.10 | Waiting-time colours | Amber after 30 min, red after 60 min | FE `waitLevel()` |
| 3.11 | Admitted-patient window on the Inpatient queue | 30 days (until a Discharge step exists) | `RegistrationService.InpatientWindowDays` |
| 3.12 | Token series | OPD `A-`, Emergency `E-`, ICU `I-`, reset daily | `RegistrationService` |
| 3.13 | Refund on cancel | Allowed for users with `PAYMENT_COLLECT` | `CancelVisitAsync` |
| 3.14 | "Not here" skip time | 15 min, then the patient is back in line with their token | FE `FrontDeskQueuePage.NOT_HERE_MINUTES` |
| 3.15 | When a doctor counts as "free" for Send in now | Started OPD today, not paused, nobody with them | FE `nextPatients()` |
| 3.16 | Lab results review (planned) | Same day: automatic return to the line when all results are in; order = emergencies → results review → token; desk marks results ready until the Lab module exists; review appointment on a later day follows the follow-up rule | planned – `FRONT-DESK-QUEUE-AND-APPOINTMENTS.md` 9.1 |
| 3.17 | Prescription lock | Doctor may amend (addendum) until the Pharmacy has dispensed the medicines | planned – Pharmacy module |
